## The word

**literally**

Delete "literally" and nobody can ever say "I literally died" again. The word's whole second career is exaggeration — people use it to mean its exact opposite — so erasing it takes the amplifier out of every tall tale while leaving the language perfectly intact. The joke lands the moment the word is gone: every overstatement in the world suddenly has to stand on its own.

## How it works

`main.py` writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It validates the entry first: exactly one word, 1–77 characters, not only whitespace.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```
